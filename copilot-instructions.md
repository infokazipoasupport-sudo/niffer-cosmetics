# Niffer Cosmetics Workspace

- Use JavaScript with React/Vite for the client and Node.js/Express for the server.
- Keep SQLite access in `server/src/database` and expose behavior through REST endpoints.
- Keep demo records clearly labeled as `TEST DATA` until verified brand information is supplied.
- Preserve the premium editorial visual direction: warm paper tones, restrained terracotta accent, serif display type, and responsive layouts.
- Run `npm run build` after client changes and exercise the API health endpoint after server changes.
- Do not hard-code payment credentials, WhatsApp numbers, or unverified business information.
